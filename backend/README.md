# LEXCONNECT Backend

This directory will store the backend API services (Express / Fastify / Nest / Python AI engine) for the LEXCONNECT ecosystem.

## Architecture Plan
- **Auth & API Service**: User authentication, case metadata endpoints, and practice management APIs.
- **RAG & AI Pipeline**: Legal retrieval-augmented generation engine grounded in statutory codes and court precedents.
- **Courtroom Engine**: Interactive trial simulation controller and evaluation scorer.
