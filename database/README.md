# LEXCONNECT Database

This directory will store database schemas, migrations, Prisma / PostgreSQL scripts, and vector storage configurations.

## Planned Datastores
- **Relational DB (PostgreSQL / Prisma)**: Users, Advocates, Cases, Hearings, Tasks, and Messages.
- **Vector DB (Pinecone / Pgvector / Chroma)**: Embedded Indian legal corpus, acts, sections, and case precedents.
